# Assets — In-Game Screenshots

Drop your in-game screenshots here and link them from the root [`README.md`](../README.md) "Screenshots" section.

## Naming Convention

```
assets/
  notesapp-overview.png
  calculatorapp-history.png
  potscanner-filters.png
  bankapp-dashboard.png
  pocketshop-modal.png
  autopackagingstation-line.png
  hitmanphone-contract.png
  moresaveslots-pagination.png
  customskateboard-carving.png
```

## Guidelines

- **Format:** PNG, max 1920px wide
- **Content:** show the mod UI in-game, no personal/save-sensitive info
- **Size:** keep each file under ~1 MB (compress via e.g. pngquant)
- Reference in README as: `![NotesApp](assets/notesapp-overview.png)`
