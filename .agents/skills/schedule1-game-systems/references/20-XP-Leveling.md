# XP/Leveling (Schedule I)

## XP Sources
| Action | XP |
|--------|----|
| Discover new mix | **80 XP** |
| Give sample (successful) | **50 XP** |
| Spray custom graffiti | **50 XP** |
| Remove cartel graffiti | **25 XP** |
| Evade police (Lethal) | **60 XP** |
| Evade police (NonLethal) | **40 XP** |
| Evade police (Arresting) | **20 XP** |
| Complete deal (personally) | **20 XP** |
| Complete deal (via dealer) | **10 XP** |
| Harvest plant | **5 XP** |
| Counteroffer accepted | **5 XP** |
| Pickpocketing | **2 XP** |
| Interrupt cartel graffiti | **50 XP** |
| Survive cartel siege | Variable |
| Complete quest | Variable |

## Leveling Table
- Per Tier: 200 XP (Street Rat) → 2,300 XP (Kingpin) per Tier
- 5 Tiers per Rank
- 11 Ranks (Street Rat → Kingpin)

## Ranks (ERank)
```
Street_Rat(0) → Hoodlum(1) → Peddler(2) → Hustler(3) → Bagman(4) →
Enforcer(5) → Shot_Caller(6) → Block_Boss(7) → Underlord(8) → Baron(9) → Kingpin(10)
```

## Bonuses Per Rank
- Higher order quantities per deal (1× → 3.5×+)
- Region unlocks
- Unlockables (new items, access passes)

## XP Farming
- **Fastest method**: Completing deals (20 XP, scalable via dealers)
- **One-time burst**: Discovering new mix recipes (80 XP)
- **Fast repeatable**: Spraying custom graffiti (50 XP)
